Before you start

Good to know.

A few practical details about hardware, driver switching and the portable app.

Which controllers are supported?

Selected Microsoft Xbox One, Elite and Series USB models, including converted One S controllers identifying as 0B12. Firmware is never modified. Support is determined by hardware IDs, not the device name. Bluetooth, wireless adapters, Xbox 360 and third-party controllers are outside this release.

PID 02D1 · 02DD · 02E3 · 02EA · 0B00 · 0B05 · 0B12
What do I need before switching?

A compatible Microsoft-signed factory Xbox driver must already be available in Windows. If it is missing, the app blocks the switch. Connect the controller and install its normal driver through Windows Update first.

Can I use the controller in games with WinUSB?

Usually not as a normal Xbox controller. Restore the factory driver when you have finished using your service tools. The app checks the active factory service before confirming restoration.

Why does it need administrator approval?

Changing a device driver is a system operation, even when the app is portable. WinUSB catalog signing also adds a local certificate to the machine certificate stores. The app does not turn off Windows signature checks or security settings.

Where are backups saved?

Recovery data and factory driver packages are kept in C:\ProgramData\NandorFIX.DriverManager. They remain available if you remove the app folder. Restore the factory driver before deleting the app if you still need normal Xbox controller operation.

What if Windows shows a security warning?

The current EXE is not Authenticode-signed, so Windows may show a SmartScreen warning. Build and package checks have passed; not every Windows and controller configuration has been validated. Review the included source and test report if needed.

Could another identical controller be affected?

The direct switch targets the selected device instance. However, Windows may select the model-specific INF for an identical controller or another USB port later. Restore the factory driver for that device too if needed. A driver package still used by another device is retained.
