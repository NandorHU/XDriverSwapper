Magyar

One S 1708 és Series 1914, valamint Seriesként jelentkező konvertált One S. Verzióválasztás, hash-ellenőrzött archív letöltés, előellenőrzés, firmware-írás és végső verzióellenőrzés. Csak egy kontroller legyen csatlakoztatva; WinUSB szükséges.

Az aktuális firmware-csomag mentése régióverziókat és sorozatszámot rögzít, majd az aktuális verzióhoz illő gyári csomagot tölti le, ha elérhető. Nem teljes flash-dump, nem kalibrációmentés. A bootloader írása blokkolt; konverziót ez a béta nem végez.

Windowsos USB-hardveren nem teszteltük. Az automatikus és szimulált tesztek sikeresek, de nem helyettesítik a hardvertesztet. Firmware-írás közben ne húzd ki a kábelt. Az alkalmazás aláíratlan. Az online letöltési útvonal Windows alatti működését nem tudtuk ellenőrizni.

English

Experimental Windows port for One S 1708 and Series 1914 / converted One S. Includes version selection, hash-pinned archive downloads, preflight, firmware writing and final version verification. Connect exactly one controller with WinUSB.

Current-package backup records actual component versions and USB serial, and downloads an exact-version stock package if available. Not a full flash dump; does not back up calibration or unique device data. Bootloader writes are blocked. No conversion support.

No Windows execution or physical USB hardware testing was available. 19 firmware backend tests passed, including a real firmware package against a simulated controller. Cached download validation passed; live backend HTTP access was blocked in the development environment. Binaries are unsigned.

Complete corresponding source and licenses are included. Firmware bytes are downloaded separately and are not bundled. Backend derived from bb441db/xboxctl, commit f83ec8c17f660df409713a83a355bd5d6fd87e1a, under 0BSD.
